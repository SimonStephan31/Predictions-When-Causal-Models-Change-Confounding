# Codebook

Data files for *Making Predictions When Causal Models Change – The Role of
Confounding* (Stephan, Placì, & Waldmann). Each file contains one row per
participant, including participants who were later excluded; the exclusion
criteria are applied in the analysis scripts.

| File | Rows | Analysis script | Final N after exclusions |
|---|---|---|---|
| `data/exp1_data.csv` | 259 | `Exp1_Analysis.qmd` | 204 |
| `data/exp2_data.csv` | 86 | `Exp2_Analysis.qmd` | 80 |
| `data/exp3_data.csv` | 134 | `Exp3_Analysis.qmd` | 128 |

General notes:

- All files are comma-separated, UTF-8 encoded. Missing values are coded `NA`.
- Free-text fields may contain line breaks inside quoted strings; read the files
  with a CSV parser (e.g., `read.csv()`), not line by line.
- P(e|c) ratings are on a 0–100 scale. The analysis scripts rescale them to 0–1.
- In all experiments, participants read about two bird populations (Western
  and Eastern) whose causal models are depicted in Figures 3 and 7 of the
  manuscript. Variables: C = ability to produce a distinct sound, A = presence
  of the hormone Amino-Regulin, E = finding a seasonal mating partner.
- Rating variables are named after the **model** they refer to, not after the
  screen position. Which model was shown on the left is coded in
  `order` (Exp. 1) or `side_order` (Exps. 2 and 3).
- Model abbreviations used in the data: `ic` = independent-causes model,
  `cccf` = confounded model, `sl` = single-link model, `ce`/`cc` = side-effect
  model.
- Prolific participant IDs have been removed. `subj_code` is a random
  identifier generated by the experiment software.

## Experiment 1 (`exp1_data.csv`)

Design: Pair (confounder condition = Pair 1 vs. control condition = Pair 2;
between subjects) × Model (within subjects). See Figure 2.

| Variable | Type | Description | Values |
|---|---|---|---|
| `subj_code` | string | Random participant identifier | |
| `condition` | integer | Between-subjects cell (pair × left/right arrangement) | `1` = Pair 1, independent-causes model left; `2` = Pair 1, confounded model left; `3` = Pair 2, single-link model left; `4` = Pair 2, side-effect model left |
| `desktop_conf` | string | Confirmation of participating via PC or laptop | `1: I confirm` |
| `attent_conf` | string | Confirmation of taking the study seriously | `1: I will take it seriously` |
| `comparison` | string | Pair of causal models | `ic_cccf` = Pair 1 (independent-causes vs. confounded model; confounder condition); `sl_cc` = Pair 2 (single-link vs. side-effect model; control condition) |
| `order` | string | Model shown on the left (and described first) | `ic left`, `cccf left` (Pair 1); `sl left`, `ce left` (Pair 2) |
| `case_1` | integer | P(e\|c) rating for the first model of the pair: independent-causes model (Pair 1) or single-link model (Pair 2) | 0–100 |
| `case_2` | integer | P(e\|c) rating for the second model of the pair: confounded model (Pair 1) or side-effect model (Pair 2) | 0–100 |
| `subj_explanation` | string | Participant's free-text explanation of their ratings (not analyzed) | free text |
| `A_check` | string | Combined result of the two comprehension test questions administered at the end of the study (including the question on the causal role of A). Participants with `incorrect` were excluded | `correct` = both questions answered correctly; `incorrect` = at least one answered incorrectly |
| `age` | integer | Age in years | |
| `tech_issues` | string | Optional free-text report of technical problems | free text; `NA` if left empty |
| `recorded_at` | datetime | Time the data were recorded (`YYYY-MM-DD hh:mm:ss`) | |

Exclusion rule (applied in the script): `desktop_conf`, `attent_conf`
confirmed and `A_check == "correct"`.

## Experiment 2 (`exp2_data.csv`)

Design: 2 (Condition: generative vs. preventive confounding link; between
subjects) × 2 (Model: weak vs. strong w_ac; within subjects). See Figure 6.

| Variable | Type | Description | Values |
|---|---|---|---|
| `condition` | integer | Between-subjects cell (polarity × left/right arrangement) | `1` = generative, w_ac = 0.9 model left; `2` = generative, w_ac = 0.1 model left; `3` = preventive, w_ac = 0.9 model left; `4` = preventive, w_ac = 0.1 model left |
| `subj_code` | string | Random participant identifier | |
| `desktop_conf` | string | Confirmation of participating via PC or laptop | `1: I confirm` |
| `attent_conf` | string | Confirmation of taking the study seriously | `1: I will take it seriously` |
| `causation_type` | string | Polarity of the confounding link A → C | `generative`, `preventive` |
| `side_order` | string | Model shown on the left, followed by the model shown on the right (w_ac × 10) | `09_01` = w_ac = 0.9 model left; `01_09` = w_ac = 0.1 model left |
| `CE_check` | string | Comprehension test answer: polarity of the C → E link | answer text (HTML formatting retained) |
| `CE_strength_check` | string | Comprehension test answer: strength of C → E in the two populations | answer text |
| `CE_check_correct` | string | Whether the C → E answers were correct | `correct` |
| `AC_check` | string | Comprehension test answer: polarity of the A → C link | answer text (positive = generative, negative = preventive) |
| `AC_strength_check` | string | Comprehension test answer: in which population the A → C link is stronger | answer text; identifies which population (Western/Eastern) had w_ac = 0.9 |
| `AC_check_correct` | string | Whether the A → C answers were correct | `correct` |
| `AE_check` | string | Comprehension test answer: polarity of the A → E link | answer text |
| `AE_strength_check` | string | Comprehension test answer: strength of A → E in the two populations | answer text |
| `AE_check_correct` | string | Whether the A → E answers were correct | `correct` |
| `instr_tests` | integer | Number of rounds needed to pass the comprehension test. Participants needing more than three rounds were excluded | 1–9 |
| `case_09` | integer | P(e\|c) rating for the model with the strong confounding link (w_ac = 0.9) | 0–100 |
| `case_01` | integer | P(e\|c) rating for the model with the weak confounding link (w_ac = 0.1) | 0–100 |
| `age` | integer | Age in years | |
| `gender` | string | Self-reported gender | `1: male`, `2: female` |
| `tech_issues` | string | Optional free-text report of technical problems | free text; `NA` if left empty |
| `recorded_at` | datetime | Time the data were recorded (`YYYY-MM-DD hh:mm:ss`) | |

Participants had to answer the comprehension test correctly to proceed, so
the recorded check answers are the final (correct) answers and all
`*_correct` variables equal `correct`.

Exclusion rule (applied in the script): `instr_tests <= 3`.

## Experiment 3 (`exp3_data.csv`)

Design: 2 (Causal model: independent-causes vs. confounded; between subjects)
× 2 (Changing base rate: b_c vs. b_a; between subjects) × 2 (Base rate value:
0.2 vs. 0.9; within subjects). See Figure 9.

| Variable | Type | Description | Values |
|---|---|---|---|
| `condition` | integer | Between-subjects cell (model × parameter × left/right arrangement) | `1` = confounded, b_c, 0.2 left; `2` = confounded, b_c, 0.9 left; `3` = confounded, b_a, 0.2 left; `4` = confounded, b_a, 0.9 left; `5` = independent-causes, b_c, 0.2 left; `6` = independent-causes, b_c, 0.9 left; `7` = independent-causes, b_a, 0.2 left; `8` = independent-causes, b_a, 0.9 left |
| `subj_code` | string | Random participant identifier | |
| `desktop_conf` | string | Confirmation of participating via PC or laptop | `1: I confirm` |
| `attent_conf` | string | Confirmation of taking the study seriously | `1: I will take it seriously` |
| `structure` | string | Causal model | `ic` = independent-causes model; `cccf` = confounded model |
| `parameter` | string | Base rate that differed between the two populations | `bc` = base rate of C; `ba` = base rate of A |
| `side_order` | string | Model shown on the left, followed by the model shown on the right (base rate × 10) | `02_09` = 0.2 model left; `09_02` = 0.9 model left |
| `ba_check` | string | Comprehension question answer: difference in b_a between the populations | answer text; in the `ba` conditions it identifies which population had b_a = 0.9 |
| `ba_check_correct` | string | Whether the b_a answer was correct | `correct` |
| `instr_tests` | integer | Comprehension-question counter. Each round comprised two questions (`ba_check`, `bc_check`); values ≤ 6 correspond to ≤ 3 rounds. Participants needing more than three rounds were excluded | 2–24 (even values) |
| `bc_check` | string | Comprehension question answer: difference in b_c between the populations | answer text; in the `bc` conditions it identifies which population had b_c = 0.9 |
| `bc_check_correct` | string | Whether the b_c answer was correct | `correct` |
| `case_09` | integer | P(e\|c) rating for the model in which the manipulated base rate was 0.9 | 0–100 |
| `case_02` | integer | P(e\|c) rating for the model in which the manipulated base rate was 0.2 | 0–100 |
| `age` | integer | Age in years | |
| `gender` | string | Self-reported gender | `1: male`, `2: female`, `3: non-binary`, `4: prefer not to say` |
| `tech_issues` | string | Optional free-text report of technical problems | free text; `NA` if left empty |
| `recorded_at` | datetime | Time the data were recorded (`YYYY-MM-DD hh:mm:ss`) | |

As in Experiment 2, the recorded check answers are the final (correct)
answers.

Exclusion rule (applied in the script): `instr_tests <= 6`.
